# Налаштування сайту

Сайт складається з трьох файлів: `index.html`, `style.css`, `script.js`.
Розміщуйте на хостингу всі три разом, в одній папці — окремо `index.html` працювати не буде.

Четвертий файл, `cloudflare-worker.js`, на хостинг НЕ завантажується — його вміст вставляється окремо в Cloudflare (розділ 3 нижче), він ховає токен Telegram-бота від сторонніх очей.

## 1. Створення Telegram-бота

1. Відкрийте в Telegram [@BotFather](https://t.me/BotFather).
2. Надішліть команду `/newbot`.
3. Вкажіть назву бота (будь-яка, наприклад «Заявки з сайту») і унікальний username, що закінчується на `bot` (наприклад `moi_zayavky_bot`).
4. BotFather надішле у відповідь **токен** виду `123456789:AAFj3k...` — це і є `TELEGRAM_BOT_TOKEN`.

## 2. Отримання chat_id

1. Знайдіть у Telegram свого щойно створеного бота за username і натисніть **Start** (або надішліть будь-яке повідомлення, наприклад «привіт»).
2. У браузері відкрийте адресу (замінивши `<TOKEN>` на ваш токен):
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
3. У відповіді (JSON) знайдіть `"chat":{"id":123456789,...}` — число `id` і є `TELEGRAM_CHAT_ID`.
   - Якщо відповідь пуста `"result":[]` — переконайтесь, що дійсно написали боту в Telegram, і оновіть сторінку.

Якщо хочете отримувати заявки не в особисті повідомлення, а в групу — додайте бота в групу, напишіть там будь-що і повторіть крок 2; `chat_id` групи буде від'ємним числом.

## 3. Налаштування Cloudflare Worker (ховаємо токен)

Сайт більше не звертається до Telegram напряму з браузера — він стукається на адресу вашого власного маленького сервера (Cloudflare Worker), а вже той, маючи токен у своїх секретах, пересилає повідомлення. Токен ніколи не потрапляє в код сторінки, тож GitHub чи будь-хто інший його не побачить.

1. Зареєструйтесь на [dash.cloudflare.com](https://dash.cloudflare.com) — безкоштовно.
2. Зліва: **Workers & Pages → Create → Create Worker**. Дайте будь-яку назву (наприклад `guardian-telegram-proxy`) і натисніть **Deploy**.
3. Натисніть **Edit code**, видаліть весь код-заготовку і вставте повністю вміст файлу `cloudflare-worker.js` (окремий файл, який я віддав разом з іншими).
4. Натисніть **Deploy** ще раз, щоб зберегти код.
5. Перейдіть у **Settings → Variables and Secrets** цього ж Worker'а і додайте два **Secret** (не Text!):
   - `TELEGRAM_BOT_TOKEN` — токен від @BotFather
   - `TELEGRAM_CHAT_ID` — ваш chat_id
6. Скопіюйте адресу Worker'а зверху сторінки (вигляд `https://guardian-telegram-proxy.ваш-нік.workers.dev`).
7. Відкрийте `script.js`, на самому початку файлу в блоці "КОНФІГУРАЦІЯ" вставте цю адресу замість плейсхолдера:

```js
var TELEGRAM_PROXY_URL = "https://guardian-telegram-proxy.ваш-нік.workers.dev";
var GOOGLE_SHEETS_URL  = "ВАШ_APPS_SCRIPT_URL_ТУТ";
var FALLBACK_PHONE     = "+380 00 000 00 00";
```

`GOOGLE_SHEETS_URL` — необов'язковий (див. розділ 4 нижче); якщо залишити плейсхолдер, архів у таблицю просто не використовується, Telegram працює як і раніше.

**Якщо ви раніше вже вставляли справжній токен прямо в `script.js`** (до цього кроку) — обов'язково зайдіть у @BotFather, надішліть `/mybots` → оберіть бота → **API Token** → **Revoke current token**, щоб старий, засвічений токен більше не працював.

## 4. Архів заявок у Google Таблиці (опційно)

Крім Telegram-сповіщення, кожна заявка може одразу дописуватись рядком у Google Таблицю — зручно, якщо хочете тримати повну історію заявок в одному місці.

1. Створіть нову Google Таблицю. У першому рядку зробіть заголовки: `Дата`, `Ім'я`, `Телефон`, `Вид страхування`, `Коментар`.
2. Відкрийте **Розширення → Apps Script**, видаліть код-заготовку і вставте:

   ```js
   function doPost(e) {
     var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
     var data = JSON.parse(e.postData.contents);
     sheet.appendRow([
       new Date(),
       data.name || '',
       data.phone || '',
       data.type || '',
       data.comment || ''
     ]);
     return ContentService.createTextOutput(JSON.stringify({status: 'ok'}))
       .setMimeType(ContentService.MimeType.JSON);
   }
   ```

3. Збережіть проєкт (значок дискети, назвіть як завгодно).
4. Натисніть **Розгорнути → Новий деплой**. Тип: **Веб-застосунок**. «Виконати від імені»: **Я**. «Хто має доступ»: **Усі**. Натисніть **Розгорнути**.
5. Google попросить авторизацію — це нормально для власного скрипта: **Додатково → Перейти до проєкту (небезпечно) → Дозволити**.
6. Скопіюйте URL веб-застосунку (закінчується на `/exec`) і вставте його як `GOOGLE_SHEETS_URL` у `script.js`.

Через особливості Apps Script браузер не може прочитати відповідь сервера (це нормально й закладено в коді), тож перевірити, що запис дійсно потрапив у таблицю, найпростіше — надіслати тестову заявку із сайту й відкрити таблицю.

## 5. Що ще персоналізувати

У файлі позначено коментарями `ЗАМІНІТЬ` — пошукайте (Ctrl+F) і заповніть:
- ім'я та прізвище (у шапці, футері та `<title>`)
- номер телефону (у трьох місцях: шапка, hero, футер)
- місто / регіон роботи
- посилання на Telegram/Viber у футері

Опційно: у секції `#hero-visual` можна замінити SVG-ілюстрацію на власне фото (`<img src="foto.jpg" alt="...">`).

## 6. Розміщення сайту (хостинг)

Найпростіші безкоштовні варіанти — сайт не потребує бекенду, але **завантажуйте всі три файли разом** (`index.html`, `style.css`, `script.js`):

- **Netlify Drop** — [app.netlify.com/drop](https://app.netlify.com/drop): перетягніть папку з усіма трьома файлами у браузер, сайт одразу онлайн.
- **GitHub Pages** — завантажте всі три файли в репозиторій, увімкніть Pages у налаштуваннях.
- **Звичайний хостинг** — залийте всі три файли в корінь сайту через FTP/файловий менеджер, якщо у вас вже є домен.

## 7. Про безпеку

Токен бота тепер зберігається тільки в секретах Cloudflare Worker'а (розділ 3) — у коді сторінки, який бачать відвідувачі й будь-хто на GitHub, його більше немає. Браузер спілкується лише з адресою Worker'а, а той уже сам, маючи токен, говорить із Telegram.
